# نقشه‌ی راه پروژه

## هدف
تولید یک گزارش مروری-تحلیلی درباره‌ی چالش‌های معماری نرم‌افزار در سرویس‌های مبتنی بر هوش مصنوعی مولد.

## مسیر کار
۱. محدودسازی مسئله و تعریف دامنه
۲. مطالعه و تحلیل منابع
۳. استخراج چالش‌های معماری
۴. دسته‌بندی بر اساس ویژگی‌های کیفی
۵. طراحی معماری مرجع برای سرویس مبتنی بر بازیابی‌افزوده
۶. ساخت ماتریس ریسک، تاکتیک و شاخص
۷. تدوین گزارش نهایی
