# تحلیل چالش‌های معماری نرم‌افزار در سرویس‌های مبتنی بر هوش مصنوعی مولد

این مخزن برای مدیریت پروژه‌ی پایانی درس معماری نرم‌افزار ساخته شده است. هدف پروژه، تحلیل معمارانه‌ی سرویس‌هایی است که مدل‌های زبانی بزرگ و هوش مصنوعی مولد به بخشی از رفتار اصلی آن‌ها تبدیل شده‌اند.

تمرکز پروژه بر تولید یک گزارش مروری-تحلیلی فارسی است؛ گزارشی که فقط منابع را خلاصه نمی‌کند، بلکه چالش‌ها، ریسک‌ها، ویژگی‌های کیفی، تاکتیک‌های معماری و شاخص‌های ارزیابی را دسته‌بندی و تحلیل می‌کند.

## ساختار مخزن

- `docs/`: برنامه‌ی کار، قالب گزارش و قواعد نگارش
- `papers/`: یادداشت‌های تحلیلی مقاله‌ها
- `books/`: یادداشت‌های تحلیلی کتاب‌ها
- `synthesis/`: جمع‌بندی‌ها و تحلیل‌های اصلی معماری
- `matrices/`: ماتریس‌های مقایسه، ریسک، تاکتیک و شاخص
- `diagrams/`: نمودارهای معماری
- `drafts/report/`: فصل‌های گزارش نهایی
- `references/`: منابع و ارجاع‌ها
- `templates/`: قالب‌های تولید LaTeX
- `scripts/`: ابزارهای ساخت خروجی
- `build/`: خروجی‌های تولیدشده در زمان بیلد؛ این پوشه در گیت نگهداری نمی‌شود

## ساخت خروجی

```bash
make tex
make pdf
python3 scripts/clean.py
```
